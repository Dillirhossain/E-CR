# E-CR
### Electronic Class Representative Management System

E-CR is a web-based platform designed to simplify and improve communication between Class Representatives (CRs), students, and university administration.

The system helps manage class-related activities, announcements, notifications, and student requests through a centralized platform.

## Project Overview

E-CR aims to make class representative management more organized, efficient, and accessible.

## Current Development

The frontend is being developed using:

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Key Features

- User Login and Registration
- Dashboard
- Class Management
- Notifications and Alerts
- Profile Management
- Join Requests
- Forgot Password
